# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique figures and code rather than people, and remember that many
contributors write in a second language.

Research figures often come from unpublished work. Treat anything someone shares about their paper as confidential,
and never ask for or post a paper that is under review.

To report behaviour that breaks this code, contact the maintainer ([@JeonSeongHu](https://github.com/JeonSeongHu))
through GitHub. Reports are handled privately.
